# libDiff

Integrated from [libView](https://github.com/liyanqing1987/libView) + [libertyParser](https://github.com/liyanqing1987/libertyParser).

## Path
`D:\workspace\project\grok\libDiff`

## Run
- `run_libDiff.bat`
- or: `C:\Users\USER\anaconda3\python.exe libView.py -i example.lib`

## Layout
- `libView.py` — GUI
- `libertyParser.py` — Liberty parser (required beside libView)
- `example.lib` — sample library for smoke test
- `libertyParser_src\` — full parser repo (examples/docs)
